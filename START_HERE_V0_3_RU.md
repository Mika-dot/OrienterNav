# OrienterNav v0.5 — подробный запуск на Windows для новичка

Эта инструкция предполагает, что вы раньше не собирали Android-приложения. Выполняйте пункты по порядку и не переходите к следующему, если текущий завершился ошибкой.

## Что в итоге будет работать

- карта OpenStreetMap на телефоне;
- поиск адреса и выбор цели долгим нажатием на карту;
- автомобильный маршрут и русские голосовые подсказки;
- автоматическое перестроение при объезде пробки или пропущенном повороте;
- плавная оценка позиции по GPS, датчикам телефона и OrienterNet;
- продолжение движения точки по ИНС при кратковременной засветке камеры;
- отбраковка пересвеченных, слишком тёмных и размытых кадров;
- отдельный OrienterNet-сервер на Windows с NVIDIA GPU.

# Часть 1. Самый простой способ получить APK

Если APK уже приложен к GitHub Actions, Android Studio для первой проверки не нужна.

1. Откройте репозиторий:
   <https://github.com/Mika-dot/OrienterNav>
2. Перейдите на вкладку **Actions**.
3. Слева выберите workflow **CI**.
4. Откройте самый свежий зелёный запуск для ветки `agent/osmlocnav-v0.3` или соответствующего Pull Request.
5. Прокрутите страницу вниз до блока **Artifacts**.
6. Нажмите **OSMLocNav-debug-apk**.
7. GitHub скачает ZIP-архив. Распакуйте его обычным проводником Windows.
8. Внутри будет файл `app-debug.apk`.

Если Actions красный, APK не появится. Откройте красный запуск, затем задачу **android** и шаг **Build APK**. В конце страницы также будет artifact `OSMLocNav-gradle-log` с полным журналом ошибки.

## Установка APK на телефон без ADB

1. Передайте `app-debug.apk` на телефон через USB, Telegram, облако или Tailscale.
2. На телефоне откройте приложение **Файлы**.
3. Нажмите `app-debug.apk`.
4. Если Android запретит установку, нажмите **Настройки**.
5. Разрешите пункт **Установка неизвестных приложений** именно для приложения **Файлы**.
6. Вернитесь назад и нажмите **Установить**.
7. После установки откройте **OrienterNav**.

Debug APK подписан тестовым Android-ключом. Для личного тестирования это нормально. Публиковать такой APK в Google Play нельзя, но прикреплять к тестовому GitHub Release можно.

# Часть 2. Скачать исходники нужной ветки

## 2.1. Установить Git

1. Скачайте Git for Windows: <https://git-scm.com/download/win>
2. Запустите установщик.
3. Во всех окнах можно оставлять значения по умолчанию.
4. После установки перезагрузите PowerShell или CMD.

Проверка в PowerShell:

```powershell
git --version
```

Должна появиться строка наподобие `git version 2.xx.x`.

## 2.2. Клонировать OrienterNav

Откройте PowerShell и выполните:

```powershell
Set-Location "$env:USERPROFILE\Desktop"
git clone -b agent/osmlocnav-v0.3 https://github.com/Mika-dot/OrienterNav.git
Set-Location ".\OrienterNav"
```

Проверка ветки:

```powershell
git branch --show-current
```

Ожидаемый ответ:

```text
agent/osmlocnav-v0.3
```

Если папка `OrienterNav` уже существует, Git напишет `destination path already exists`. Не клонируйте поверх неё. Либо переименуйте старую папку, либо обновите существующую копию:

```powershell
Set-Location "$env:USERPROFILE\Desktop\OrienterNav"
git fetch origin
git switch agent/osmlocnav-v0.3
git pull
```

# Часть 3. Установить Android Studio и SDK

## 3.1. Android Studio

1. Скачайте Android Studio: <https://developer.android.com/studio>
2. Запустите установщик.
3. Оставьте отмеченными:
   - Android Studio;
   - Android SDK;
   - Android Virtual Device.
4. После установки запустите Android Studio.
5. В первом мастере выберите **Standard**.

## 3.2. Проверить Android SDK 35

1. В Android Studio откройте **More Actions → SDK Manager**.
2. На вкладке **SDK Platforms** отметьте **Android 15.0 (API 35)**.
3. На вкладке **SDK Tools** отметьте:
   - Android SDK Build-Tools;
   - Android SDK Platform-Tools;
   - Android SDK Command-line Tools (latest).
4. Нажмите **Apply → OK** и дождитесь загрузки.

## 3.3. JDK 17

Android Studio содержит собственный JDK. Для сборки из CMD удобнее установить Temurin 17:

1. Откройте <https://adoptium.net/temurin/releases/?version=17>.
2. Выберите Windows, x64, JDK, MSI.
3. В установщике включите пункты **Set JAVA_HOME** и **Add to PATH**.
4. Закройте и снова откройте PowerShell.

Проверка:

```powershell
java -version
```

В первой строке должна быть версия `17`.

# Часть 4. Собрать APK самостоятельно

## Вариант A — через Android Studio

1. Запустите Android Studio.
2. Нажмите **Open**.
3. Выберите папку `Desktop\OrienterNav`, а не папку `app`.
4. Нажмите **Trust Project**, если появится вопрос.
5. Дождитесь сообщения **Gradle sync finished**. Первый запуск может скачивать файлы 10–30 минут.
6. Откройте меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
7. Дождитесь сообщения **APK(s) generated successfully**.
8. Нажмите ссылку **locate** в уведомлении.

Готовый файл:

```text
OrienterNav\app\build\outputs\apk\debug\app-debug.apk
```

## Вариант B — одной командой PowerShell

Откройте PowerShell в корне проекта:

```powershell
Set-Location "$env:USERPROFILE\Desktop\OrienterNav"
.\gradlew.bat clean testDebugUnitTest assembleDebug
```

Успешная сборка заканчивается строкой:

```text
BUILD SUCCESSFUL
```

Проверка наличия APK:

```powershell
Get-Item ".\app\build\outputs\apk\debug\app-debug.apk"
```

## Если написано `JAVA_HOME is not set`

Закройте PowerShell, откройте новый и снова выполните `java -version`. Если Java не найдена, переустановите Temurin 17 с пунктом **Set JAVA_HOME**.

## Если Android SDK не найден

Узнайте путь SDK в Android Studio: **SDK Manager → Android SDK Location**. Обычно это:

```text
C:\Users\ВАШЕ_ИМЯ\AppData\Local\Android\Sdk
```

Создайте в корне проекта файл `local.properties` со строкой без кавычек:

```properties
sdk.dir=C:\\Users\\ВАШЕ_ИМЯ\\AppData\\Local\\Android\\Sdk
```

Не загружайте `local.properties` в GitHub: он относится только к вашему компьютеру.

# Часть 5. Установить APK через USB и ADB

Этот способ удобнее, если APK приходится ставить много раз.

## 5.1. Включить режим разработчика

1. На Android откройте **Настройки → О телефоне**.
2. Семь раз нажмите **Номер сборки**.
3. Вернитесь назад.
4. Откройте **Для разработчиков**.
5. Включите **Отладка по USB**.

## 5.2. Подключить телефон

1. Подключите телефон нормальным USB-кабелем с передачей данных.
2. На телефоне появится вопрос о доверии компьютеру.
3. Отметьте **Всегда разрешать** и нажмите **Разрешить**.

Проверка в PowerShell:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" devices
```

Рядом с серийным номером должно быть слово `device`, а не `unauthorized`.

Установка с заменой предыдущей тестовой версии:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r ".\app\build\outputs\apk\debug\app-debug.apk"
```

Ожидаемый ответ: `Success`.

# Часть 6. Развернуть OrienterNet-сервер на Windows

## 6.1. Что требуется

- Windows 10/11 x64;
- NVIDIA GPU с актуальным драйвером;
- Python 3.11 x64;
- примерно 16 ГБ оперативной памяти;
- желательно около 12 ГБ видеопамяти;
- свободное место на диске для PyTorch, модели и кеша OSM.

## 6.2. Установить Python 3.11

1. Скачайте Python 3.11 x64 с <https://www.python.org/downloads/windows/>.
2. На первом экране обязательно отметьте **Add python.exe to PATH**.
3. Нажмите **Install Now**.

Проверка:

```powershell
py -3.11 --version
```

## 6.3. Автоматическая установка

Откройте обычный PowerShell:

```powershell
Set-Location "$env:USERPROFILE\Desktop\OrienterNav\orienternet-service"
.\INSTALL_WINDOWS.bat
```

Скрипт создаст `.venv`, поставит зависимости, CUDA-сборку PyTorch, клонирует OrienterNet и PerspectiveFields и создаст `.env`.

Установка долгая. Не закрывайте окно, пока не появится итог проверки.

## 6.4. Положить модель

Рекомендуемый путь:

```text
C:\Users\ВАШЕ_ИМЯ\Desktop\OrienterNav\orienternet_mgl.ckpt
```

Если модель хранится в другом месте, откройте файл:

```text
OrienterNav\orienternet-service\.env
```

И укажите полный путь:

```dotenv
ORIENTERNET_CHECKPOINT=C:\Models\orienternet_mgl.ckpt
```

## 6.5. Настроить сервер

В `.env` должны быть строки:

```dotenv
ORIENTERNET_HOST=0.0.0.0
ORIENTERNET_PORT=1000
ORIENTERNET_API_KEY=придумайте-длинный-случайный-ключ
ORIENTERNET_MOCK=0
```

Запомните API-ключ. Точно такой же ключ вводится на телефоне.

## 6.6. Запустить и проверить

Запуск:

```powershell
.\START_WINDOWS.bat
```

Не закрывайте это окно во время поездки.

В новом PowerShell:

```powershell
Set-Location "$env:USERPROFILE\Desktop\OrienterNav\orienternet-service"
.\CHECK_WINDOWS.bat
.\CHECK_WINDOWS.bat warmup
```

После warmup в ответе должно быть:

```json
"device": "cuda"
```

Если указано `cpu`, нейросеть не использует NVIDIA GPU. Проверьте драйвер и CUDA-сборку PyTorch.

# Часть 7. Соединить телефон и компьютер через Tailscale

1. Установите Tailscale на Windows: <https://tailscale.com/download/windows>.
2. Установите Tailscale на Android из Google Play.
3. Войдите в один аккаунт на обоих устройствах.
4. На Windows нажмите значок Tailscale около часов.
5. Найдите адрес компьютера вида `100.x.x.x`.
6. На телефоне откройте браузер и введите:

```text
http://100.x.x.x:1000/health
```

Подставьте реальный Tailscale IP компьютера. Если появился JSON со статусом сервера, связь работает.

Если страница не открывается:

1. Проверьте, что `START_WINDOWS.bat` продолжает работать.
2. Проверьте `.env`: `ORIENTERNET_HOST=0.0.0.0`.
3. Разрешите Python в брандмауэре Windows для частных сетей.
4. Проверьте, что Tailscale подключён на обоих устройствах.

# Часть 8. Первый запуск OrienterNav

1. Откройте **OrienterNav**.
2. Разрешите точную геолокацию.
3. Разрешите камеру.
4. Нажмите шестерёнку справа сверху.
5. В поле сервера введите:

```text
http://100.x.x.x:1000
```

6. Введите API-ключ из `.env`.
7. Оставьте интервал кадров `2000` мс.
8. Включите **Использовать визуальную коррекцию**.
9. Превью камеры сначала лучше оставить выключенным.
10. Нажмите **Сохранить**.

## Построить первую поездку

1. Нажмите **Моё место**.
2. Введите адрес в поле **Куда едем?** и нажмите стрелку.
3. Выберите подходящий результат.
4. Либо долго нажмите прямо на карте в точке назначения.
5. Нажмите **Поехали**.

Во время движения:

- зелёная точка означает надёжную позицию;
- жёлтая точка и надпись **Уточняю позицию** означают, что абсолютная коррекция давно не приходила;
- при засветке появится сообщение, что приложение продолжает по ИНС;
- если съехать с синей линии, после нескольких подтверждений появится **Перестраиваю маршрут**;
- долгое нажатие на верхнюю карточку включает или скрывает диагностическое превью камеры.

# Часть 9. Как правильно проверить новую навигацию

Не начинайте с длинной поездки. Сделайте четыре отдельных теста.

## Тест 1 — обычный маршрут

1. Выберите цель на расстоянии 2–3 км.
2. Проедьте маршрут без отклонений.
3. Проверьте движение маркера, курс карты и голосовые команды.

## Тест 2 — перестроение

1. Постройте маршрут.
2. На безопасном перекрёстке намеренно поверните на соседнюю улицу.
3. Не возвращайтесь сразу на старую линию.
4. Навигатор должен определить устойчивое отклонение и построить новый маршрут.

## Тест 3 — засветка камеры

1. Во время прямого движения ненадолго закройте камеру или направьте её на яркий участок.
2. Должно появиться сообщение о плохом кадре.
3. Маркер должен продолжать приблизительное движение по ИНС, а погрешность постепенно расти.
4. После возвращения нормального изображения камера должна дать несколько согласованных поправок и уточнить точку без одиночного прыжка.

## Тест 4 — поворот без камеры

1. Перед безопасным поворотом ненадолго закройте камеру.
2. Выполните поворот.
3. Гироскоп должен изменить курс оценки.
4. После восстановления камеры положение должно плавно уточниться.

Телефон закрепляйте жёстко. Если он болтается в подстаканнике или его берут в руки, автомобильная ИНС будет получать движения самого телефона вместо движения машины.

# Часть 10. Самостоятельно создать GitHub Release с APK

Сначала убедитесь, что APK установлен и проверен в реальной поездке.

1. Переименуйте файл:

```text
app-debug.apk → OrienterNav-v0.5.0-beta-debug.apk
```

2. Откройте <https://github.com/Mika-dot/OrienterNav/releases>.
3. Нажмите **Draft a new release**.
4. В поле **Choose a tag** введите:

```text
v0.5.0-beta
```

5. Нажмите **Create new tag**.
6. В **Target** выберите ветку или коммит, который был реально протестирован.
7. Название релиза:

```text
OrienterNav v0.5.0 beta
```

8. В описание вставьте:

```markdown
Тестовая версия гибридного OSM-навигатора.

- двумерная GPS/INS/OrienterNet оценка положения;
- автоматическое перестроение маршрута;
- фильтрация визуальных выбросов;
- контроль пересвета и размытия камеры;
- поиск адреса и русские голосовые инструкции;
- обновлённый интерфейс.

Это debug APK для полевых испытаний, не production-релиз.
```

9. Перетащите `OrienterNav-v0.5.0-beta-debug.apk` в область **Attach binaries**.
10. Отметьте **Set as a pre-release**.
11. Не отмечайте **Set as the latest release** для первой тестовой версии.
12. Нажмите **Publish release**.

После публикации скачайте APK уже со страницы Release и ещё раз проверьте, что файл открывается и устанавливается.

# Часть 11. Что прислать при ошибке

Если что-то не работает, приложите:

1. точный шаг этой инструкции;
2. полный текст ошибки, а не только последнюю строку;
3. скриншот экрана телефона;
4. вывод:

```powershell
java -version
py -3.11 --version
git branch --show-current
```

5. для Android-сборки файл `gradle.log` или весь вывод `gradlew.bat`;
6. для сервера вывод `CHECK_WINDOWS.bat warmup`;
7. модель телефона и версию Android;
8. описание крепления телефона в автомобиле.

Не публикуйте в открытом issue настоящий API-ключ из `.env`.
